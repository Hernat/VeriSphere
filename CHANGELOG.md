# Changelog

All notable changes to VeriSphere will be documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/), with the **Pre-V1 Release Policy** documented in [RELEASING.md](./RELEASING.md): the project starts at `0.1.0`; patches and small evolutions stay on `0.x.y`; **`1.0.0` is reserved for the moment the founder substitution success criterion is validated for ≥ 1 week of personal usage.**

## [Unreleased]

### Added

- Initial repository documentation skeleton: `LICENSE` (MIT), `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `RELEASING.md`, `CHANGELOG.md` (Story 1.2).
- `.gitattributes` for consistent line-ending normalisation across platforms (Story 1.2).
- `/local/` entry in `.gitignore` per the AC list (Story 1.2).
- `AUTHORS.md` documenting maintainership and AI pair-programming tooling (post-Story-1.2 addition; see commit `ebd6345`).
- GitHub Actions CI workflows (Story 1.3): `pr.yml` (lint + unit tests + assemble-debug), `main.yml` (same + Detekt), `release.yml` (signed assembleRelease + GitHub Release upload on tag, currently unsigned until Story 7.3 wires the keystore).
- Detekt 1.23.7 wired into Gradle with the three architecture-mandated rules: `GlobalCoroutineUsage`, `ForbiddenMethodCall` (println / print), and a placeholder for the missing-`@Serializable`-on-repository-types rule scoped to Story 1.10.
- `.github/pull_request_template.md` with the architecture-pattern discipline checklist.
- `SecureStorage` over `EncryptedSharedPreferences` with `MasterKey.Builder` (AES-256-GCM, non-extractable) — Story 1.4. Single shared file `vs_secure_prefs` for all V1 persisted state; nine-method API (`readJson`/`writeJson`/`readString`/`writeString`/`readLong`/`writeLong`/`readBoolean`/`writeBoolean`/`clear`); `AppContainer.secureStorage` lazy field; instrumented round-trip test.
- `RateLimitRepository` (interface + impl) — 30 captures / device / UTC-day, persisted via `SecureStorage` (keys `rate_limit_count_today`, `rate_limit_date`), reset at UTC midnight, debug-bypassable via `BuildConfig.SKIP_RATE_LIMIT`. `AppContainer.rateLimitRepository` lazy field. JVM unit tests cover first-call-of-day, 30+1 cap, midnight rollover with injected `Clock`, debug bypass, persistence-survives-instance, and 50-way concurrent contention. Story 1.5.
- In-app version check + `version-info.json` schema (Story 6.1, FR22, AR18, D3.9). `VersionChecker.checkForUpdates()` is fire-and-forgotten from `VeriSphereApplication.onCreate` on `AppContainer.applicationScope` (`SupervisorJob() + Dispatchers.IO`), fetches `https://raw.githubusercontent.com/Hernat/VeriSphere/main/version-info.json` over the shared OkHttp client, parses to `VersionInfo(latestVersion, downloadUrl, releasedAt)` with integer-SemVer comparison against `BuildConfig.VERSION_NAME`, and writes / clears `update_available_version` + `update_available_download_url` SecureStorage keys. Silent on every failure (network / non-200 / malformed JSON / missing field). `version-info.json` seeded at repo root with `latestVersion=0.1.0` + placeholder Drive URL pending Story 7.3.
- `UpdateBanner` composable + bubble update-dot overlay (Story 6.2, FR23, UX-DR10). New stateless `ui/banner/UpdateBanner.kt` (full-width `surfaceVariant` Surface with leading info icon + body text + filled Download `Button` + trailing dismiss `IconButton`); file-level `buildUpdateDownloadIntent(downloadUrl)` factory producing `Intent.ACTION_VIEW + FLAG_ACTIVITY_NEW_TASK`. `BubbleOverlay` gains `hasUpdateAvailable: Boolean` parameter rendering an 8 dp circular dot (`vs_update_dot` = `#9AA0A6` light / `#5F6368` dark) on the upper-right edge — orthogonal to every `BubbleState` variant. Reactive `AppContainer.updateAvailableVersion: StateFlow<String?>` mirrors `SecureStorage` via a new `notifyUpdateAvailableChanged` lambda-seam threaded through `VersionChecker`; invoked only on the three state-mutating branches, NEVER on failure paths (CDN #4 — defends in-memory state against transient network loss). `BubbleOverlayService.setContent` collects the flow and forwards `hasUpdateAvailable = updateVersion != null` to `BubbleOverlay`. Adds `material-icons-extended` dependency for `Icons.Outlined.Info` / `Close`. Strings: `update_banner_text` / `update_banner_download` / dismiss + dot a11y descriptions. 6 new JVM tests (VersionCheckerTest amendments) + 11 new androidTest methods (UpdateBannerUiTest × 3 + UpdateBannerIntentFactoryTest × 3 + BubbleOverlayUpdateDotUiTest × 5). No new permissions. APK delta +17 KB vs Story 6.1 baseline.
- Banner show/dismiss/persist logic + install-cleanup of all 3 update-banner SecureStorage keys (Story 6.3, FR24, epics L899-916). New `KEY_UPDATE_BANNER_DISMISSED_FOR_VERSION = "update_banner_dismissed_for_version"` const in `VersionChecker.companion` (CDN #1 single-source-of-truth). `VersionChecker` notify-seam signature refactored to `notifyUpdateAvailableChanged: (version: String?, downloadUrl: String?) -> Unit` (CDN #6 pairing invariant — both values atomic). New seam `notifyDismissedVersionCleared: () -> Unit` fired ONLY on the equal-or-older clear branch (CDN #4 — NEVER on failure paths or non-https rejection); equal-or-older branch now clears all 3 keys (epics L912 install-cleanup). `AppContainer` adds 2 new lazy `MutableStateFlow`s (`_updateAvailableDownloadUrl` + `_updateBannerDismissedForVersion`) + public read-only StateFlow surfaces + `dismissUpdateBanner()` method writing the snapshotted current version via `applicationScope.launch { withContext(NonCancellable + Dispatchers.IO) { ... } }` install-lifetime pattern (Story 5.2 P4 / Story 5.3 CDN #5 precedent). `AppContainer._updateAvailableVersion` lazy initializer now gated through new `gatePersistedVersion(persisted, current)` `@VisibleForTesting` companion helper reusing the `isNewerSemVer` SemVer parser — closes deferred-work D2 (Med, Story 6.2 review): user-upgrade-without-network no longer flashes "old version available" banner/dot. `HistoryScreen` + `HistoryContent` extended with 3 new params (`updateBanner: UpdateBannerPayload?` data class + 2 callbacks); Scaffold body refactored to `Column { if (banner) UpdateBanner; Box > when(state) }` so banner renders above all 3 HistoryUiState arms (UX spec L609 + Flow 4). MainActivity `setContent` `else -> HistoryScreen(...)` arm collects 3 StateFlows + computes predicate (`version != null && downloadUrl != null && version != dismissed`) + adds 2 new private handlers `onUpdateBannerDismiss` (delegates to AppContainer) + `onUpdateBannerDownload(url)` wrapping `startActivity(buildUpdateDownloadIntent(url))` in typed `ActivityNotFoundException` + `SecurityException` catches — closes deferred-work D7 (Low, Story 6.2 review): malformed `Uri.parse` no longer crashes (CDN #8 + UX-DR1 calm-over-loud). Story 6.3 makes ZERO changes to BubbleOverlay / BubbleOverlayService / UpdateBanner composables — the dot follows `update_available_version` flow per epics L893+L914 (CDN #3); the dismissal flag is orthogonal. 15 new JVM tests (VersionCheckerTest amendments × 9 covering Task 2.3 invariants + 3-key clear ordering + new dismissed-cleared seam parity across 6 branches; AppContainerUpdateBannerTest × 6 covering `gatePersistedVersion` D2 helper) + 5 new androidTest methods (`HistoryScreenUpdateBannerTest`). No new strings / colors / manifest / permissions / dependencies. APK delta +17 KB vs Story 6.2 baseline (2,591,335 bytes; data class + Column refactor + setContent restructure cost; well within NFR2 ≤ 10 MB at ~26% of budget).

### Changed

- Bumped `androidx.security:security-crypto` from `1.1.0-alpha06` to `1.1.0` GA (Maven check 2026-05-06; deferred-work item from Story 1.1 closed).
- `proguard-rules.pro`: added `-dontwarn com.google.errorprone.annotations.**` so R8 minify succeeds against the new Tink dependency pulled in by `security-crypto:1.1.0` GA.

## [0.1.0] - unreleased

### Added

- Project bootstrap from Android Studio Empty Activity Compose starter (Story 1.1).
- Manifest hardening: exactly 5 permissions, `allowBackup="false"`, network security config with HTTPS-only enforcement.
- `BuildConfig.GEMINI_API_KEY` injection from `local.properties` or the `GEMINI_API_KEY` environment variable; build fails fast when the key is absent.
- `BuildConfig.SKIP_RATE_LIMIT` debug-only bypass flag (release hard-codes `false`).
- Material 3 theme with `dynamicColor=false`, auto-follow-system, full UX Step 8 palette in `colors.xml` + `values-night/colors.xml`, typography overrides at 18 / 16 / 14 / 12 sp, `VSSpacing` scale at 4 / 8 / 12 / 16 / 24 / 32 dp.
- `AppContainer.kt`, `VeriSphereApplication.kt`, `util/Logger.kt` skeleton with `tag(name)` and `redact(value)` helpers.
- `version.properties` source-of-truth at `MAJOR=0`, `MINOR=1`, `PATCH=0`.
- ProGuard / R8 release rules: strip `Log.d/v/i`, keep `@Serializable` types.
- `.gitignore` covering Android build artefacts, IntelliJ per-developer config, local secrets, BMad workflow internals.
